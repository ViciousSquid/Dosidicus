# Wiki replacements

Replacement pages for the [project wiki](https://github.com/ViciousSquid/Dosidicus/wiki),
for pages that CANARY has made out of date. Each file has the same name as the
wiki page it replaces and holds the whole page: open that page on the wiki,
choose Edit, and paste the file over it.

Pages not here were checked and are still accurate. Once the wiki is updated
this folder can be deleted.
