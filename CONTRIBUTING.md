# Contributing to Squid Exchange

Thank you for helping the ocean grow.

## How to contribute

1. Export your squid from Dosidicus.
2. Create a new folder inside `squids/` using your squid's name.
3. Place the exported ZIP inside the folder.
4. Add a `README.md` describing your squid.
5. Open a Pull Request.

## Folder structure

```
squids/

    SquidName/

        README.md
        exported_squid.zip
```

## README

Tell us about your squid.

Interesting things include:

- personality
- unusual behaviours
- memorable experiences
- fears
- favourite activities
- anything future caretakers should know

Your README does not need to include technical statistics.

Those will eventually be generated automatically.
